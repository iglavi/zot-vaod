# ליצי - בוט וואטסאפ משפחתי מבוסס Claude

בוט שיושב בקבוצות וואטסאפ משפחתיות, ועונה כשפונים אליו בשם ("ליצי") או מתייגים אותו.
התשובות מגיעות מ-**Claude Managed Agent** משלכם, כולל זיכרון נפרד לכל קבוצה. הבוט גם יודע
לקבוע תזכורות ("ליצי, תזכיר ביום רביעי ב-18:00 להביא עוגה") ולשלוח אותן בזמן.

מסמך זה מסביר הכול צעד-צעד, גם אם אתם לא מתכנתים.

---

## 1. איך זה עובד (בקצרה)

- **וואטסאפ:** הבוט מתחבר לוואטסאפ כ"מכשיר מקושר" (בדיוק כמו וואטסאפ-web), דרך ספריית
  [Baileys](https://github.com/WhiskeySockets/Baileys). בחיבור הראשון משתמשים ב-**קוד התאמה**
  (Pairing Code) - קוד בן כמה ספרות שמקלידים בטלפון, בלי צורך לסרוק QR (נוח כשהבוט רץ בענן).
  פרטי ההתחברות נשמרים בקובץ על **Volume** קבוע ב-Railway, כדי שלא תצטרכו להתחבר מחדש בכל
  הפעלה של הבוט.
- **הסוכן (Claude Managed Agent):** לכל קבוצת וואטסאפ יש "שיחה" (session) נפרדת מול הסוכן, כך
  שהוא זוכר את ההקשר של כל קבוצה בנפרד. ה-session נשמר גם הוא בקובץ על ה-Volume.
- **מתי הבוט מגיב:** רק כשההודעה מכילה את השם "ליצי" או מתייגת את מספר הבוט. שאר ההודעות
  נשמרות **בזיכרון זמני בתהליך** (ברירת מחדל: 200 הודעות אחרונות לכל קבוצה) כדי שיהיה לסוכן
  הקשר כשמבקשים ממנו סיכום - אבל הן **לא נשלחות ל-API** ו**לא עולות כסף** עד שמישהו באמת פונה
  לבוט.
- **תזכורות:** כשמבקשים מהבוט תזכורת, הוא (הסוכן) קורא לכלי (tool) פנימי שקובע תזכורת בקובץ
  על ה-Volume. תהליך רקע בודק כל 20 שניות אם הגיע הזמן של תזכורת כלשהי, ואם כן - שולח אותה
  לקבוצה. אזור הזמן: `Asia/Jerusalem`.
- **בטיחות:** רשימה לבנה (`ALLOWED_CHAT_IDS`) של מזהי קבוצות מורשות. כל קבוצה או צ'אט פרטי
  שלא ברשימה - מתעלמים ממנו לגמרי.

## 2. מה תצטרכו

1. **חשבון ב-[Railway](https://railway.app)** - שם הבוט ירוץ 24/7.
2. **מפתח API של Anthropic** (`ANTHROPIC_API_KEY`) מ-[platform.claude.com](https://platform.claude.com)
   (יש ליצור מפתח תחת Settings -> API Keys). שימו לב שהשימוש ב-Managed Agents כרוך בעלות לפי
   שימוש (טוקנים) - בדקו את התמחור בקונסולה.
3. **מספר טלפון ייעודי לבוט** - מספר שדרכו הבוט "יהיה" בוואטסאפ (מכשיר מקושר). זה **לא**
   חייב להיות מספר "אמיתי" נפרד לגמרי - אבל הכי נוח שיהיה מספר שאינו בשימוש שוטף שלכם
   (למשל סים נוסף/מספר מחברת שמאפשרת מספר וירטואלי שמקבל SMS/שיחה לאימות), כדי שהבוט לא
   "יתנגש" עם השימוש הרגיל שלכם בוואטסאפ. המספר הזה צריך להיות **חבר** בקבוצות המשפחתיות
   הרלוונטיות (או שתוסיפו אותו אחרי החיבור הראשון).
4. **Node.js מותקן במחשב שלכם** (גרסה 20 ומעלה) - רק כדי להריץ פעם אחת סקריפט הקמה, ולעשות
   את חיבור הפיירינג הראשוני. הורדה: [nodejs.org](https://nodejs.org).

## 3. הרצה מקומית ראשונית (לפני הפריסה ל-Railway)

זה השלב שבו יוצרים את הסוכן ב-Claude, ומבצעים את חיבור הוואטסאפ הראשון. עושים את זה פעם
אחת מהמחשב שלכם, ואז מעבירים הכול ל-Railway.

```bash
cd whatsapp-bot
npm install
cp .env.example .env
```

פתחו את הקובץ `.env` שנוצר, ומלאו:

```
ANTHROPIC_API_KEY=sk-ant-...        # המפתח שלכם
WHATSAPP_PHONE_NUMBER=9725XXXXXXX   # מספר הבוט, בפורמט בינלאומי, בלי + ובלי רווחים
```

### 3.1 יצירת הסוכן (Managed Agent) פעם אחת

```bash
npm run setup:agent
```

הסקריפט יוצר ב-Claude "Environment" ו-"Agent" (בעברית, עם הוראות התנהגות ותזכורות), ובסוף
ידפיס משהו כזה:

```
AGENT_ID=agent_01Abc...
ENVIRONMENT_ID=env_01Xyz...
```

**העתיקו שתי השורות האלה לתוך קובץ ה-.env שלכם.** אין צורך להריץ את הסקריפט הזה שוב - הוא
יוצר את הסוכן פעם אחת, ומכאן הבוט רק "משוחח" מולו.

### 3.2 חיבור ראשוני לוואטסאפ עם קוד התאמה

עדיין לא מילאתם `ALLOWED_CHAT_IDS` - זה בסדר, נעשה את זה אחרי שנגלה את מזהי הקבוצות.

```bash
npm start
```

בטרמינל תראו לאחר כמה שניות משהו כזה:

```
==================================================
קוד ההתאמה (Pairing Code) שלך: ABCD-1234
בטלפון: הגדרות -> מכשירים מקושרים -> קישור מכשיר -> קישור עם מספר טלפון, והזינו את הקוד.
==================================================
```

בטלפון שממנו הבוט "ידבר" (המספר שהגדרתם ב-`WHATSAPP_PHONE_NUMBER`):

1. פתחו את **וואטסאפ**.
2. **הגדרות** -> **מכשירים מקושרים** -> **קישור מכשיר**.
3. בחרו **"קישור עם מספר טלפון במקום"** (Link with phone number instead) - זה מה שמאפשר
   הקלדת קוד במקום סריקת QR.
4. הקלידו את המספר שדרכו הבוט מתחבר (אותו מספר), ואז הקלידו את הקוד שהודפס בטרמינל.

תוך כמה שניות תראו בטרמינל `החיבור לוואטסאפ פעיל ✅`. זה גם יוצר תיקייה `data/baileys_auth`
עם פרטי ההתחברות - **את זה נעביר ל-Volume ב-Railway בהמשך**, כדי לא לעשות את זה שוב.

### 3.3 גילוי מזהי הקבוצות (ALLOWED_CHAT_IDS)

עכשיו, כשהבוט מחובר אך עדיין לא מאושר לאף קבוצה: שלחו הודעה כלשהי (מכל אחד) באחת מקבוצות
המשפחה שהבוט חבר בהן. בטרמינל תראו שורה כזו:

```
הודעה מקבוצה לא מאושרת: 120363012345678901@g.us (כדי לאשר את הקבוצה, הוסיפו את המזהה הזה ל-ALLOWED_CHAT_IDS)
```

העתיקו את המזהה (המחרוזת שמסתיימת ב-`@g.us`) לתוך `.env`, עם פסיק בין כמה מזהים אם יש כמה
קבוצות:

```
ALLOWED_CHAT_IDS=120363012345678901@g.us,120363019876543210@g.us
```

עצרו את הבוט (Ctrl+C), הריצו שוב `npm start` כדי לטעון את הרשימה המעודכנת, ווודאו שעכשיו
פנייה בשם "ליצי" בקבוצה מקבלת תשובה.

מוכנים? עוצרים את הבוט המקומי (Ctrl+C) ועוברים לפריסה ב-Railway.

## 4. פריסה ל-Railway

### 4.1 יצירת פרויקט

1. ב-[Railway](https://railway.app), **New Project** -> **Deploy from GitHub repo**, ובחרו
   את הריפו הזה (או **Empty Project** ואז חברו את הריפו/העלו את הקוד).
2. אם הריפו מכיל גם תיקיות/פרויקטים אחרים (כמו כאן), ודאו ש-**Root Directory** של השירות
   מוגדר ל-`whatsapp-bot` (Settings -> Root Directory), כדי ש-Railway יריץ את `npm install`
   ו-`npm start` מתוך התיקייה הנכונה.
3. Railway יזהה אוטומטית פרויקט Node.js (בזכות `package.json`) ויריץ `npm install` ואז
   `npm start`.

### 4.2 הוספת Volume (חשוב!)

בלי Volume, כל הפעלה מחדש של הבוט (דיפלוי חדש, קריסה, וכו') תמחק את חיבור הוואטסאפ ואת
התזכורות/הזיכרון של הקבוצות - ותצטרכו לחבר מחדש עם קוד פיירינג חדש בכל פעם.

1. בשירות ב-Railway: לשונית **Volumes** (או דרך Settings) -> **New Volume**.
2. הגדירו **Mount Path**: `/data`.
3. הוסיפו משתנה סביבה `DATA_DIR=/data` (ראו בהמשך).

כך כל הקבצים החשובים (`baileys_auth`, `sessions.json`, `reminders.json`) יישמרו על דיסק קבוע
ולא יימחקו בין הפעלות.

### 4.3 משתני סביבה (Variables)

בלשונית **Variables** של השירות ב-Railway, הוסיפו:

| משתנה | ערך | הערה |
|---|---|---|
| `ANTHROPIC_API_KEY` | המפתח שלכם | |
| `AGENT_ID` | מה שהודפס ב-`npm run setup:agent` | |
| `ENVIRONMENT_ID` | מה שהודפס ב-`npm run setup:agent` | |
| `WHATSAPP_PHONE_NUMBER` | מספר הבוט | בפורמט בינלאומי, בלי + |
| `BOT_NAME` | `ליצי` | אפשר לשנות |
| `ALLOWED_CHAT_IDS` | מזהי הקבוצות שגיליתם | מופרד בפסיקים, בלי רווחים |
| `DATA_DIR` | `/data` | חייב להתאים ל-Mount Path של ה-Volume |
| `TIMEZONE` | `Asia/Jerusalem` | |

### 4.4 חיבור וואטסאפ ראשוני ב-Railway (אם עדיין לא חיברתם מקומית)

שתי אפשרויות:

**אפשרות א' (מומלצת - הכי פשוט):** אחרי החיבור המקומי בסעיף 3, פשוט **העלו את תוכן תיקיית
`data/` הקיימת** (במיוחד `data/baileys_auth`) ל-Volume של Railway, כדי שהבוט יעלה כבר מחובר.
ניתן לעשות זאת דרך `railway ssh` / `railway volume` (ה-CLI של Railway), או פשוט לוותר על
העלאה ולבצע במקום זאת את אפשרות ב'.

**אפשרות ב' (חיבור ישירות דרך הענן):** פשוט תפרסו את הבוט ל-Railway בלי תיקיית `data/`
מקומית, ותצפו בלוגים (**Deployments -> View Logs**) - הבוט ידפיס שם את קוד ההתאמה בדיוק כמו
בטרמינל המקומי. הקלידו אותו בטלפון (הגדרות -> מכשירים מקושרים -> קישור עם מספר טלפון) תוך
כ-60 שניות מהופעתו בלוג. מרגע שהחיבור מצליח, פרטי ההתחברות נשמרים ל-Volume ולא תצטרכו לעשות
זאת שוב (כל עוד לא מוחקים את ה-Volume).

> אם לא הגדרתם `ALLOWED_CHAT_IDS` מראש - עשו את תהליך הגילוי שבסעיף 3.3, רק שהפעם תצפו
> בלוגים של Railway במקום בטרמינל המקומי, ותעדכנו את המשתנה `ALLOWED_CHAT_IDS` ב-Variables
> (עדכון משתנה סביבה גורם ל-Railway להפעיל מחדש את השירות אוטומטית).

### 4.5 בדיקה שהכול עובד

בקבוצה מאושרת, שלחו הודעה כמו `היי ליצי, מה נשמע?` ווודאו שמתקבלת תשובה. נסו גם:

```
ליצי, תזכיר ביום רביעי ב-18:00 להביא עוגה
```

ואמורים לקבל אישור, ולאחר מכן - בזמן שנקבע - הודעת התזכורת עצמה.

## 5. שאלות נפוצות

**איך מוסיפים את הבוט לעוד קבוצה?** הוסיפו את המספר של הבוט לקבוצה החדשה (כמו כל איש קשר),
שלחו הודעה כלשהי בקבוצה כדי שיירשם הלוג של המזהה, והוסיפו אותו ל-`ALLOWED_CHAT_IDS`.

**איך מנתקים את הבוט מוואטסאפ (למשל כדי לחבר מחדש)?** בטלפון: הגדרות -> מכשירים מקושרים ->
בחרו את המכשיר של הבוט -> התנתקות. ואז מחקו את תיקיית `baileys_auth` בתוך ה-Volume (או פשוט
את כל ה-Volume אם אין בו תזכורות/שיחות חשובות), ואתחלו את השירות מחדש כדי לקבל קוד התאמה חדש.

**אפשר לשנות את המודל של הסוכן (למשל למודל זול/מהיר יותר)?** כן - ערכו את `model:` בקובץ
`scripts/setup-agent.js`, והריצו שוב `FORCE_RECREATE=1 npm run setup:agent` (זה ייצור סוכן
וסביבה חדשים, ותצטרכו לעדכן את `AGENT_ID`/`ENVIRONMENT_ID` ב-Variables של Railway - שימו לב
ששיחות/הזיכרון הקיים לכל קבוצה יתחילו מחדש כי הן שייכות לסוכן הישן).

**כמה זה עולה?** התשלום הוא ל-Anthropic לפי טוקנים בפועל (תלוי בכמות ההודעות שמופנות לבוט
ובאורך ההקשר שנשלח), בנוסף לעלות הריצה של Railway עצמו. אין מנוי חודשי קבוע מעבר לזה.

**מה קורה אם הבוט נופל / Railway מפעיל מחדש?** בזכות ה-Volume, החיבור לוואטסאפ, מיפוי
השיחות לכל קבוצה, והתזכורות השמורות - כולם נשארים כמו שהיו. הבוט פשוט מתחבר מחדש לוואטסאפ
עם אותם פרטי התחברות, בלי צורך בקוד פיירינג חדש.

## 6. מבנה הקוד (לסקרנים)

```
whatsapp-bot/
  scripts/setup-agent.js   סקריפט חד-פעמי ליצירת ה-Agent וה-Environment ב-Claude
  src/
    config.js              טעינת משתני סביבה + נתיבי אחסון
    logger.js               לוגים פשוטים עם חותמת זמן
    store.js                אחסון JSON גנרי עם כתיבה אטומית לדיסק
    messageBuffer.js        זיכרון-רקע זמני (בזיכרון RAM) של הודעות אחרונות לכל קבוצה
    reminders.js             שמירת תזכורות בקובץ + תהליך רקע ששולח אותן בזמן
    agent.js                 עטיפה ל-Managed Agents API: session לכל קבוצה, טיפול בכלי התזכורת
    whatsapp.js              חיבור Baileys, קוד התאמה, זיהוי פניות לבוט, שליחת תשובות
    index.js                 הפעלת הכול יחד
```
